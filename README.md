# GymBro

Генератор программ тренировок. Работает полностью в браузере, без сервера, офлайн.

**Демо:** https://newendik.github.io/gymbro/

## Возможности

- 5 шагов настройки: цель → опыт → частота → инвентарь → название
- 71 упражнение с техниками выполнения
- Детерминированный генератор (одинаковые параметры → одинаковый план)
- PWA: устанавливается на домашний экран, работает офлайн
- Планы в `localStorage` устройства

## Деплой

Файлы в корне репозитория. GitHub Pages подключается автоматически.

```
Settings → Pages → Deploy from branch → main / (root)
```
